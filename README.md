# HeadCursor (Team Quantum Codex)
Control your computer cursor with your head, using only a webcam. Voice typing in English and Tamil.
Built on our earlier HeadStart prototype and extended for COMPUTE50.

## How to run
1. Install Python (3.11, 3.12 or 3.13) and tick "Add Python to PATH".
2. In this folder, open a terminal and run:
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python head_cursor.py
3. First run downloads a small face model (needs internet).
4. Look at the screen centre and press C to calibrate.
   S = scroll, [ and ] = sensitivity, Q = quit
5. Open classroom.html in Chrome for the quiz page.
